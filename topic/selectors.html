Element Selector

  1. An Element Selector (also called a Type Selector) in CSS targets HTML elements directly by their node name (tag name) to apply styles across all matching elements in the document.
  2. Element Selectors uses the TAG NAME to select the HTML TAG/ELEMENT.
  3. Example: h1{};
  4. Element Selector selects all the elements from the webpage for that tag.
  5. Can be used to group multiple tags, if same CSS needs to be applied for them elt1, elt2, elt3 ... elt n{}. All the elt s will have same css properties.

ID Selector

  1. ID selector is used to select the HTML element using its ID attribute.
  2. Example: #idOfTheElement{};.
  3. The ID selector will select all the elements with the ID name.
  4. The ID selector must be prefixed with "#", other wise the element wil not be selected
