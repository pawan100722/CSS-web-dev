Element Selector

  1. An Element Selector (also called a Type Selector) in CSS targets HTML elements directly by their node name (tag name) to apply styles across all matching elements in the document.
  2. Element Selectors uses the TAG NAME to select the HTML TAG/ELEMENT.
  3. Example: h1{};
  4. Element Selector selects all the elements from the webpage for that tag.
  5. Can be used to group multiple tags, if same CSS needs to be applied for them elt1, elt2, elt3 ... elt n{}. All the elt s will have same css properties.

ID Selector

  1. ID selector is used to select the HTML element using its ID attribute.
  2. Example: #idOfTheElement{};.
  3. The ID selector will select all the elements with the ID name.
  4. The ID selector must be prefixed with "#", other wise the element wil not be selected
  5. Every element must have unique ID name, otherwise it will create bugs

Class Selector

  1. Multiple elements can have same class name.
  2. Classes are specifically used to select or target multiple elements.
  3. The name must be prefixed with a dot. Example: .classNameOfElt
  4. Just define the CSS using the class selector, use the class name to any number of tag that needs to be styled for that CSS.
  5. One HTML tag can have multiple classes separated by space. Like class="class1 class2 class3... class-n"
    1. The classes must be defined in CSS or stylesheet.
  6. When two classes define the same property on an element, the rule listed last in the CSS stylesheet applies—regardless of their order in the HTML `class` attribute.

Universal Selector

  1. Universal selector is used to target all the elements in the HTML page.
  2. Universal selectors are mostly used to reset the webpage or remove default styling of the HTML elements, like padding and margin or set font family of the web page.
  3. It is written as asterisk. Example: *{CSS properties}
  4. The universal selector selects all the tags in the DOM tree, even HTML, BODY, META etc.

Descendant Selector

  1. It selects or target all the child selectors.
  2. Example: parentName chileName{}
  3. It targets all the same elements even if they are nested

Direct Child Selector

  1. It selects the Direct child only, not the nested elements
  2. Example: parentName > childName

Specificity of CSS Selectors

ID selector have highest specificity, after ID, CLASS selector have the priority and after that ELEMENT selector.
