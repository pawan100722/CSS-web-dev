Introduction

  1. CSS means Cascading Style Sheets.
  2. It is a stylesheet language used to write presentation of a HTML webpage
  3. CSS is used to change/manipulate the look of a HTML page
  4. CSS can be implemented in 3 ways:
    5. Types
    Inline CSS: Write CSS in HTML tag using "style" attribute of the tag
    Internal CSS: Write CSS in same HTML file, using <style>tag inside HEAD tag
    External CSS:
    1. The "href" attribute of the tag will help the CSS file.
    2. Write CSS in separate CSS file and link the file to the HTML files using <link>tag.
    3. The "rel" attribute, which specifies the relationship, must have "stylesheet" as value
    4. The style tag must be used inside the HEAD tag
  5. Inline CSS will have highest priority.
  6. Other than inline CSS, priority is set by ordering, the CSS which gets executed later will be applied.
  7. If the external CSS file gets executed after internal CSS the the external CSS will be applied and vice-versa.

Change tab image/icon of the web page

  • It can be changed using <link> tag.
  • The Link tag must have rel="shortcut icon" and type="image/x-icon"
  • The "href" attribute must have link of the icon
